# Community Library Management System

Compact React solution for BIWA2110 Assignment 2.

## Requirements covered
- React components, useState and useEffect
- React Router
- Controlled forms and basic validation
- localStorage
- Dashboard with low-stock highlighting
- Book add/update/delete
- Stock add and borrowing with transaction history
- User login and add/update/delete users
- Responsive CSS

## Run
1. Open this folder in VS Code/terminal.
2. Run `npm install`
3. Run `npm run dev`
4. Open the Vite URL shown in the terminal.
